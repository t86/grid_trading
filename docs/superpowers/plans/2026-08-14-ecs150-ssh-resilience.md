# ECS 150 SSH 链路韧性实施计划

目标是在不进入云厂商后台、不触碰交易策略与仓位的前提下，为 150 提供可验证的 SSH 抗扫描、经 111 的备用入口和本机自动恢复。

1. 新增 SSH 抗扫描安装脚本：写入独立 drop-in，先执行 `sshd -t`，再 reload；验证有效参数、现有直连和 111 到 150 的连接。
2. 新增反向隧道安装脚本：150 使用专用密钥主动连 111，只在 111 的 `127.0.0.1:22150` 监听；固定 111 主机密钥，远端公钥限制为指定监听端口；验证服务重启和实际登录。
3. 新增 SSH 看门狗与安装脚本：通过仅允许本机、强制 `/bin/true` 的专用密钥完成真实 SSH 握手；连续 3 次失败且不在 10 分钟冷却期时，仅在 `sshd -t` 成功后重启 SSH listener；不终止已有用户会话。
4. 运行目标测试、shell 语法检查和安全审查；提交并推送 `main`。150 从该 commit 建立独立基础设施工作树，避免发布其落后的 148 个业务提交，然后严格按前三项顺序部署并演练。

回滚：每个安装器保留旧配置；SSH hardening 可恢复 drop-in 后 reload，隧道与看门狗可分别 disable 对应 unit/timer。现有 Web、runner、订单和仓位不在本次变更范围。
